# 🛡️ Smart CCTV Threat Detection System

### AI-powered surveillance for detecting potential threats and abnormal activities from CCTV footage.

> 🎥 Real-time video analysis  
> 🤖 YOLO11-based object detection  
> 🔫 Custom weapon detection  
> 👤 Person tracking & movement analysis  
> 🚨 Event-based threat identification

---

## 🚨 The Problem

Traditional CCTV systems continuously record video, but they still depend heavily on humans to monitor the footage.

With multiple cameras and long monitoring periods, suspicious events can be missed or detected late.

### 💡 Our Solution

We are developing an AI-based CCTV system that automatically analyzes video frames and identifies potentially threatening or abnormal activities.
